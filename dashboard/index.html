🐍 iAgent-Pay Python SDK Quickstart

Guía rápida de integración para desarrolladores. Copia este snippet para iniciar transacciones autónomas de forma gratuita durante los primeros 2 años.

2 Años Gratis 
from iagent_pay.agent_pay import AgentPay

# 1. Inicializa el SDK en la red deseada (ej. BASE, POLYGON)
agent = AgentPay(chain_name="BASE")

# 2. Tu agente ejecuta pagos de forma autónoma (Sin comisiones por 2 años)
tx_hash = agent.transfer(
    recipient_address="0xF29E7b5BC7fdd6C4d9B4DE9f68De31739FBB1526",
    amount_eth=0.005
)

print(f"Transacción enviada exitosamente: {tx_hash}")
